# FP3級 合格ナビ（日本FP協会・資産設計提案業務）

FP技能検定3級（受験先：**日本FP協会** ／ 実技は「**資産設計提案業務**」）に合格するための学習サイトです。
**直感 → 理解 → 得点** の3層構造で、スマホのスキマ時間でも学べるように設計しています。

- ビルド不要の**静的サイト**（素のHTML / CSS / JavaScript のみ）
- 図解はすべて**インラインSVG**（画像ファイル不使用）
- 学習進捗・設定は**ブラウザのlocalStorage**に保存（サーバー不要）
- **ダークモード**対応、モバイルファースト（下部ナビ・片手操作を想定）

> ⚠️ **法令基準日について**：本サイトの数値は制作時点の試験基準（`js/data/curriculum.js` の `EXAM.lawBaseDate`）に基づきます。
> NISA枠・iDeCo拠出限度額・基礎控除など税制改正で変わりやすい数値には「改正注意」バッジを付けています。
> 受験前に、必ず**日本FP協会の公式サイトで最新の試験範囲**とつき合わせて確認してください。

## GitHub Pages で公開する手順（Git に不慣れな方向け）

### 方法A：ブラウザだけで完結（推奨・かんたん）

1. GitHub にログインし、右上「＋」→ **New repository** をクリック
2. **Repository name** に好きな名前（例：`fp3-goukaku`）を入力し、**Public** を選択して **Create repository**
3. 作成直後の画面で **uploading an existing file** のリンクをクリック
4. このフォルダ（`fp3-study-site`）の**中身をすべて**ドラッグ＆ドロップでアップロード
   - `index.html` がリポジトリの**一番上（ルート）**に来るようにします（`fp3-study-site` フォルダごとではなく、中身を入れる）
5. 下の **Commit changes** ボタンを押す
6. リポジトリ上部の **Settings** → 左メニュー **Pages** を開く
7. **Build and deployment** の Source を **Deploy from a branch** にし、
   Branch を **main** ／ フォルダを **/ (root)** にして **Save**
8. 数十秒〜数分待つと、同じ Pages 画面の上部に公開URLが表示されます
   - 形式：`https://（あなたのユーザー名）.github.io/（リポジトリ名）/`

### 方法B：コマンド（Git）で公開

```bash
# このフォルダ内で実行
git init
git add .
git commit -m "FP3級 合格ナビ フェーズ1"
git branch -M main
# 事前に GitHub 上で空のリポジトリを作成しておく
git remote add origin https://github.com/ユーザー名/リポジトリ名.git
git push -u origin main
```

その後、GitHub の **Settings → Pages** で Branch=`main` / フォルダ=`/ (root)` を選んで Save。

> すべてのリンクは**相対パス**で書かれているため、`https://ユーザー名.github.io/リポジトリ名/` のような
> プロジェクトページ形式でもリンクが壊れません。

## データの保存とリセット

- 学習データはブラウザの `localStorage`（キーは `fp3.*`）に保存されます。**サーバーには一切送信されません。**
- ブラウザの開発者コンソールで以下を実行すると、全データを初期化できます。

```js
FP3.Store.resetAll(); location.reload();
```

## 実装フェーズ（すべて完了）

- **フェーズ1**：サイト骨格 — ダッシュボード、進捗/ストリーク/復習/バッジ/ダークモード、カリキュラム定義、共通クイズエンジン
- **フェーズ2**：分野①「ライフプランニングと資金計画」の全単元（図解・インタラクティブ教材・ミニチェック込み）を完全実装
- **フェーズ3**：残り5分野（リスク管理・金融資産運用・タックスプランニング・不動産・相続事業承継）を完全実装。合計6分野・38単元
- **フェーズ4**：実技（資産設計提案業務）— 8種類の資料（キャッシュフロー表・バランスシート・係数表・保険証券・源泉徴収票・登記事項証明書・路線価図・雑誌記事風資料）を再現した資料読み取り演習22問。「資料のどこを見るか」ハイライト解説モード付き
- **フェーズ5**：模試モード — 学科模試（60問・90分・6分野から均等抽出）と実技模試（20問・60分）。CBT風の1問ずつ表示・見直しフラグ・全問一覧ジャンプ・タイマー自動提出・採点後の分野別/資料別レーダーチャート・弱点分野へのリンク付き

### 学科模試の問題バンクについて
`js/data/exam-bank.js` に、各単元のミニチェックと同じ内容の問題を159問集約している（id を単元ミニチェックと共通にすることで、模試で間違えた問題も復習デッキに正しく積み上がる）。模試実行時に6分野から各10問をランダム抽出して60問を構成する。

## 新しい単元を追加するときのメモ（開発者向け）

1. `js/data/curriculum.js` の該当分野に単元を追加し、`href` に単元ページのパス（例：`chapters/life/1-fp-kihon.html`）を設定する
2. 単元ページを作成し、ミニチェックを次のように設置する：

```html
<div id="mini"></div>
<script>
  FP3.Quiz.mountMiniCheck(document.getElementById('mini'), questions, { unitId: 'life-1' });
</script>
```

- ホームのロードマップ・分野一覧・進捗集計は `curriculum.js` を自動参照するため、**単元定義を足すだけ**でUIに反映されます。
